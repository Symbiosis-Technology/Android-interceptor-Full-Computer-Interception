功能明细

两个端分开列，不混在一起说

本地 DNS 过滤

基于 VpnService 自建 DNS 应答，按域名规则拦截广告；上游走多个公共 DNS 加系统 DNS，单路超时自动切换。

开屏与弹窗跳过

按目标应用与关键词匹配开屏广告，命中后自动跳过，支持白名单避免误跳。

权限与风险管控

敏感权限调用监控与拦截，风险行为三档策略；高风险动作走通知、悬浮横幅、全屏处置页三重提示。

内置输入法

40 万词条拼音库与简拼候选、1914 个 emoji、符号面板，键盘内可直接与 AI 对话并把回复上屏。

离线语音输入

打包 sherpa-onnx 中英双语流式模型（int8 198 MB），录音与识别放在独立进程，边说边出字，不联网。

文件管理与双开

文件管理器申请全盘访问，shell 与系统接口双通道；双开助手通过多用户能力安装第二个实例。

hosts 域名拦截

广告投放、统计追踪、开屏与弹窗三类内置库，勾选生成 0.0.0.0 映射，写入前自动备份，最多留 10 份。

自定义域名

一行一个，随类别一起写入；待写入列表可搜索，写入状态直接标在表格里。

开机启动项管理

读取 HKCU / HKLM / Wow6432Node 的 Run 键与两个启动文件夹；禁用是移到隔离区，不删除原配置。

网络连接查看

调用 netstat 与 tasklist，把 TCP 连接映射到进程名，可过滤，需要时结束进程并二次确认。

权限检测与提权

启动即检测管理员权限，没有权限时给出「以管理员身份重启」入口，不静默失败。

AI 助手与日志

默认智谱 GLM-4-flash，接口地址、模型、Key 可替换；操作写本地 app.log，可在设置页查看。

常见问题

装之前先看这几条

Windows 版为什么需要管理员？

hosts 文件在系统目录，普通账户没有写权限。软件会检测权限并在左下角给「以管理员身份重启」按钮，也可以直接右键 exe 选「以管理员身份运行」。

会弹「未知发布者」或 SmartScreen 吗？

会。exe 没有代码签名证书，Windows 会对新下载的可执行文件提示风险，点「更多信息 → 仍要运行」即可，也可用 SHA-256 核对文件。

hosts 拦截会影响正常上网吗？

只把列出的域名解析到 0.0.0.0，其它域名正常解析，不接管流量、不装驱动。误伤可以只勾一类，或从自定义列表移除；任何一次写入都能从备份还原。

Android 版为什么这么大？

体积主要来自离线语音模型（int8 198 MB）和双架构原生库，其次是 22 MB 拼音词库。首次点键盘语音会把模型复制到应用私有目录，需预留约 400 MB 空间。

两端的配置会同步吗？

不会，也没有云端账号。Windows 配置在本机用户目录，Android 配置在应用私有目录，各自独立。

怎么彻底卸载？

Windows 版先在软件里点「清除拦截」还原 hosts，再删整个文件夹。Android 版卸载前建议先关闭 VPN 拦截与输入法。
